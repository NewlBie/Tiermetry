# Tiermetry Homepage Architecture

## Target Feeling

The Home page should feel premium because it is clear, useful, and controlled. Expensive UI is not louder; it makes priority obvious and broken states rare.

## Section Jobs

| Section | Job | Visual Mode |
|---|---|---|
| Greeting | Set mood and location context | Editorial header |
| Intent Search | Let users state what they want | Functional input |
| Quick Routes | Fast category entry | Compact shortcuts |
| Live Around You | Nearby live places/inventory | Venue shelf |
| Events This Week | Scheduled moments | Date-led event shelf |
| Trending Activities | Browse categories | Icon grid/list |
| Featured Skills | Guided learning sessions | Taller editorial cards |
| Premium | Upgrade value | Quiet benefit-led panel |

## Navigation Principles

- Keep horizontally scrolling shelves focused on one object type.
- Use section headers as navigation promises, not decoration.
- Make `View more` lead to a page with the same object type and filters.
- Preserve scroll position when returning from detail pages.
- Avoid stacking multiple large promotional tiles before inventory.

## Premium Feel Checklist

- Fewer competing accents per viewport.
- Stable image fallbacks.
- Clear hierarchy between section title, card title, metadata, and CTA.
- No visible overflow warnings.
- Motion supports feedback; it does not distract from choice.
- High contrast without relying only on neon color.
