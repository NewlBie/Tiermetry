# Tiermetry UI Review Checklist

- Can the object type be recognized without reading the title?
- Are there at least three non-color differentiators from nearby object types?
- Is the first visible cue aligned with the section job?
- Does the card still communicate its type when the image is missing?
- Are typography, radius, spacing, and colors using existing tokens where practical?
- Does the component avoid overflow on small screens and long content?
- Does the action language match the object type?
- Does the section contain only one semantic object type?
